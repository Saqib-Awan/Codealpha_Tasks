# Iris Flower Classification using Machine Learning

## Project Overview

This project implements a machine learning classification model to identify iris flower species based on flower measurements. The classification task is performed using the Iris dataset available in Scikit-learn.

The model predicts one of the following species:

- Setosa
- Versicolor
- Virginica

The project demonstrates the complete machine learning workflow including:
- Data loading
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Model training
- Model evaluation
- Feature importance analysis

---

# Dataset Information

The Iris dataset contains 150 observations with the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target Variable:
- Species of Iris flower

Dataset Source:
- Scikit-learn built-in dataset
