# Car Price Prediction using Machine Learning

## Project Overview

This project develops a machine learning regression model to predict car-related performance using automobile specifications such as horsepower, engine size, acceleration, weight, and fuel efficiency.

The project demonstrates the complete machine learning workflow including:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Regression model training
- Model evaluation
- Feature importance analysis

The objective is to analyze automobile data and build an accurate predictive model using machine learning techniques.

---

# Dataset Information

The dataset contains multiple automobile characteristics and technical specifications.

## Features Included

- Cylinders
- Displacement
- Horsepower
- Weight
- Acceleration
- Model Year
- Origin
- Car Name

## Target Variable

- Miles Per Gallon (MPG)

Dataset Source:
- Automobile Dataset
