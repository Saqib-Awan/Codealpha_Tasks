# Sales Prediction using Machine Learning

## Project Overview

This project develops a machine learning regression model to predict product sales based on advertising expenditure across multiple media platforms.

The analysis explores how investments in advertising channels influence sales performance and demonstrates the practical application of regression techniques in business analytics.

The project includes:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Regression model training
- Model evaluation
- Prediction analysis

---

# Dataset Information

The dataset contains advertising budgets spent on different marketing platforms along with corresponding sales values.

## Features

- TV Advertising Budget
- Radio Advertising Budget
- Newspaper Advertising Budget

## Target Variable

- Sales

Dataset Source:
- Advertising Dataset

# Model Evaluation

The regression model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

The model demonstrated strong predictive performance for sales forecasting.

---

# Key Findings

- TV advertising had the strongest influence on sales performance.
- Radio advertising also contributed positively to sales growth.
- Newspaper advertising showed comparatively lower impact on sales prediction.
