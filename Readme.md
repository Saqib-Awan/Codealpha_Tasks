# CodeAlpha Data Science Internship — Projects Repository

## Overview

This repository contains all the completed projects developed during my Data Science Internship at CodeAlpha. The internship focused on building practical skills in data science, machine learning, and predictive modeling using Python and its ecosystem of libraries.

Through these projects, I gained hands-on experience in:
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Data visualization
- Supervised machine learning (classification and regression)
- Model evaluation and performance analysis

---

## Completed Projects

### 1. Iris Flower Classification
A classification model that predicts iris flower species based on sepal and petal measurements.

**Key Highlights:**
- Supervised classification problem
- Random Forest Classifier
- High model accuracy
- Feature importance analysis

---

### 2. Sales Prediction using Machine Learning
A regression model that predicts sales based on advertising expenditure across TV, Radio, and Newspaper channels.

**Key Highlights:**
- Linear Regression model
- Correlation analysis between advertising and sales
- Strong relationship between TV advertising and sales
- Model evaluation using MAE, MSE, and R² score

---

### 3. Car Price Prediction using Machine Learning
A regression model that predicts vehicle-related performance (MPG) based on automobile specifications.

**Key Highlights:**
- Random Forest Regressor
- Data cleaning and feature encoding
- Handling categorical variables
- Feature importance analysis
